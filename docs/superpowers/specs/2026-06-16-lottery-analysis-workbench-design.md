# 四彩种数据分析工作台设计

日期：2026-06-16

## 背景

当前项目已经完成“数运合参”预测页，支持双色球、福彩3D、七乐彩、快乐8四个彩种，后端可以读取本地历史开奖数据，前端可以生成预测号码并展示历史依据、个人时空依据和最近开奖。

下一阶段目标是补齐“喜欢买彩票的人会真正用来分析”的数据工具层。分析功能不替代预测结果，也不承诺提升中奖概率，而是帮助用户查看历史走势、热冷遗漏和号码形态，形成自己的娱乐分析判断。

## 目标

- 四个彩种都支持基础历史分析。
- 分析区放在当前页面下方，随彩种切换同步更新。
- 支持 `近30期 / 近60期 / 近120期` 窗口切换。
- 展示热号、冷号、遗漏、走势、形态分布和增强版最近开奖。
- 与现有黑金后台视觉保持一致，不新增独立页面。
- 所有分析只基于历史数据和当前预测结果，不接入投注、支付、登录或用户保存。

## 非目标

- 不做复杂专业杀号系统。
- 不做中奖概率承诺或收益暗示。
- 不做账号体系、收藏夹、历史个人记录。
- 不在第一版加入策略回测，回测作为后续阶段。
- 不改变现有预测接口的核心行为。

## 用户体验

页面结构保持现有首屏预测盘不变，在下方新增 `数据分析` 工作台区块。

分析区顶部包含：

- 标题：`数据分析`
- 窗口切换：`近30期`、`近60期`、`近120期`
- 当前彩种摘要：样本期数、最新期号、最新开奖日期

分析区主体分为四个模块：

1. `热冷遗漏`
   - 展示热号榜、冷号榜、遗漏榜。
   - 号码以小球或紧凑列表显示。
   - 每个号码显示出现次数或遗漏期数。

2. `走势视图`
   - 展示最近 N 期的轻量走势格。
   - 横向是号码或号码段，纵向是期号。
   - 命中点高亮，悬停显示期号、日期、号码。
   - 第一版优先做可读性，不追求彩票网站级完整大图。

3. `形态分布`
   - 用条形或紧凑统计块展示号码结构。
   - 不同彩种使用不同指标。

4. `近期开奖`
   - 升级现有最近开奖列表。
   - 展示期号、日期、开奖号、与当前预测号码重合数。
   - 标注是否包含当前窗口热号或冷号。

## 彩种差异

### 双色球

- 红球和蓝球分开统计。
- 红球指标：热号、冷号、遗漏、奇偶比、大小比、和值区间、连号数量。
- 蓝球指标：热号、冷号、遗漏、近期出现次数。
- 走势视图：红球 1-33，蓝球单独小区块 1-16。

### 福彩3D

- 按百位、十位、个位分别统计 0-9。
- 展示每一位的热号、冷号、遗漏。
- 形态指标：和值、跨度、组三、组六、豹子。
- 走势视图：三列位置走势，每列 0-9。

### 七乐彩

- 基本号和特别号分开统计。
- 基本号指标：热号、冷号、遗漏、奇偶比、大小比、和值区间、连号数量。
- 特别号指标：热号、冷号、遗漏。
- 走势视图：基本号 1-30，特别号单独小区块。

### 快乐8

- 统计 1-80 的出现频次和遗漏。
- 走势视图不展示完整密集 80 列大表，第一版按区间分组：1-10、11-20、...、71-80。
- 形态指标：区间分布、奇偶比、和值、与上一期重号数量。

- `game_key`：`ssq`、`3d`、`qlc`、`kl8`
- `window`：允许 `30`、`60`、`120`，默认 `30`

## 前端设计

新增分析区 DOM：

- `analysisWorkbench`
- `analysisWindowTabs`
- `analysisSummary`
- `analysisHotCold`
- `analysisTrend`
- `analysisShape`
- `analysisRecentDraws`

前端交互：

- 彩种切换时同步加载预测和分析。
- 窗口切换时只刷新分析区，不重新生成预测。
- 分析接口失败时显示“分析数据暂不可用”，预测区不受影响。
- 加载中显示紧凑骨架状态，避免页面闪动。

视觉风格：

- 使用现有黑金变量、边框和小球样式。
- 走势图使用紧凑网格，不做大面积彩色图。
- 卡片只用于分析模块，不嵌套卡片。

## 数据规则

窗口数据按开奖日期倒序取最近 N 期。

热号：

- 按出现次数降序。
- 同次数按号码升序。
- 主号和特别号分开。

冷号：

- 按出现次数升序。
- 同次数按号码升序。

遗漏：

- 从最新一期向前查找某号码上次出现距离。
- 窗口内未出现的号码遗漏值为窗口大小。

重合数：

- 用当前预测号码与最近开奖号码求交集。
- 双色球、七乐彩主号和特别号分开计数后合并展示。

## 错误处理

- `game_key` 不支持返回 404 或 400。
- `window` 非允许值时回退为 30。
- 历史数据为空时返回空数组和 `draw_count=0`，前端显示空状态。
- 分析接口失败不影响现有 `POST /api/predict`。

## 测试计划

后端测试：

- 四个彩种都能返回分析 payload。
- 窗口参数只接受 30、60、120，异常值回退。
- 热号、冷号、遗漏在手工样本下结果正确。
- 福彩3D 按位置统计。
- 快乐8 区间分布正确。
- 空数据返回稳定结构。

前端验证：

- 彩种切换后分析区同步更新。
- 窗口切换只刷新分析，不重新提交预测表单。
- 桌面和移动视口无横向溢出。
- 走势图和表格文本不重叠。
- 分析接口失败时显示错误状态。

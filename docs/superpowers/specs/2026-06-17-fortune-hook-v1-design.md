# 玄学命中钩子 V1 设计说明

## 目标

首页推荐需要从“号码解释”升级成“个人化命中感”。用户提交姓名、历法、出生日期、时辰、出生地和当前城市后，系统先给出一句看得懂的命中判断，再展示本命财格、今日宜忌、取号逻辑、避开号和每个号码的结构化释义。

## 产品范围

- 新增 `fortune_hook`：包含 headline、subline、tags，用于首页高优先级展示。
- 新增 `metaphysics_profile`：包含本命财格、主气、财星元素、喜用元素、避让元素、今日宜忌和取号逻辑。
- 新增 `avoid_numbers`：给出本期不建议入局的几个号码和原因。
- 升级 `number_reasons`：每个号码从一句话改为五行角色、入选原因、组合位置三段式说明。
- 不承诺中奖，不把 AI 直接输出为号码；AI 只参与五行偏好和主题提取。

## 算法原则

- 本命财格由本地个人时空向量推导，DeepSeek 特征只做偏好校正。
- 财星元素采用“主气所克为财”的稳定映射，喜用元素采用财星和生扶元素。
- 避开号选择未入选且落在避让元素上的号码，避免用户觉得系统只会解释已选号码。
- 文案模板保持确定性，同一输入在同一开奖日返回稳定结果。

## 前端体验

- 首页表单后新增一条横向“命中钩子”信息带。
- 玄学解读卡片从长段落改为命格、宜忌、取号逻辑的摘要。
- 号码释义列表展示号码位阶、五行角色、入选原因和组合位置。
- 移动端保持单列，不让文字挤压号码球和主操作。

## 验证

- 预测引擎测试覆盖新增字段、避开号不与推荐号重复、号码释义三段式。
- API 测试覆盖 `/api/predict` payload 和首页 shell 文案。
- 前端 JS 做语法检查，浏览器做桌面和移动截图检查。

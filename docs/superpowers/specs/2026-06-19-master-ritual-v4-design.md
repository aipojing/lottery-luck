# 玄学推荐可信度 V4：大师起盘版设计

日期：2026-06-19

## 背景

当前首页已经有本命财格、今日财签、避开号、逐号释义和解释链，但用户看到结果时仍容易觉得“像是随机文案”。这一版要把核心抓手前移：不是强调预测准确，而是强调一套可复述的起盘路径，让用户相信这组号是从个人信息一步步推出来的。

## 目标

- 首页主动作从“生成财运号”升级为“开始起盘”，形成仪式感。
- 新增“大师起盘”结果卡，把个人信息到号码的路径串成闭环。
- 后端 payload 明确输出起盘结构，不让前端只靠静态文案包装。
- 逐号释义从“为什么入选”升级为“在这盘里的角色”，让号码有位置感。
- 保存历史记录时保留起盘结果，方便后续复盘页继续讲同一套逻辑。

## 非目标

- 不承诺未来开奖命中，不把玄学叙事包装成真实预测能力。
- 不改动彩票基础算法权重的大方向；号码仍由本地算法生成，AI 只做命理特征和文案辅助。
- 不引入登录、云端用户档案或付费体系。

## 产品叙事

首页结果要形成一条用户能看懂的链路：

1. 定命盘：姓名、生日、历法、时辰、出生地、当前城市进入个人时空底盘。
2. 排本命财格：根据五行向量得到主气、财星、托财元素和本命财格。
3. 定今日财局：结合开奖日、城市和时辰，给出今日财位、旺时和宜忌。
4. 取喜用尾数：把喜用元素映射到数字尾数。
5. 避冲煞号：把忌用元素和已选号码剔除，生成避开号。
6. 落财运号：按稳财、偏财、守财模式收束成最终号码。

## 前端呈现

- 表单主按钮改为“开始起盘”。
- 仪式进度文案统一为“起盘”，避免“生成”和“起局”混用。
- 在一眼命中卡后新增“大师起盘”卡，首屏向下滚动后优先看到：
  - 一句起盘断语；
  - 六步起盘链路；
  - 喜用尾数和避开尾数。
- 原“AI 解读分层”改为“起盘解读”，表达更贴合玄学抓手。

## 验证

- 后端预测测试覆盖 `master_ritual` 的字段、六步标签、喜用尾数和最终号码。
- API 静态资源测试覆盖首页文案与前端渲染函数。
- 前端行为测试覆盖点击“开始起盘”后仪式状态、起盘卡渲染和历史记录保存字段。
- 保留娱乐免责声明，不弱化“不构成投注建议”。
